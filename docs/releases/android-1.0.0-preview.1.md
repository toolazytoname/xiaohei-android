## 选择版本
- **普通版「小黑」**：星光图标，推荐一般用户，无需 Root。包名 `studio.weichao.xiaohei`。
- **增强版「小黑·增强」**：琥珀加号图标，仅建议 OnePlus 8T 实验。包名 `studio.weichao.xiaohei.common`，受控设备工具仍需确认。
- Android 8+、arm64；两包可并存。无鸿蒙原生版，华为/鸿蒙兼容性未验证。
