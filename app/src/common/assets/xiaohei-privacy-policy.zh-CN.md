## 3. 普通版功能与数据处理边界

普通版提供：文字与语音聊天、本机语音转写、由您自行配置的 AI / TTS / STT 接口、以及经您当场确认后打开系统设置或系统照片选择器。您也可以选择把相册、相机或文件作为聊天附件。模型服务不是我们运营的云，地址、模型名和密钥都由您填写。

当前 `commonRelease` 打包会排除下列 native 库。普通版公开预览**不提供**终端环境、FFmpeg、OCR 或媒体转换：

- FFmpeg 相关媒体转换库及 `libffmpegkit`、`libc++_shared`
- ML Kit OCR JNI
- MediaPipe text JNI
- 终端环境：`libbusybox.so`、`libbash.so`、`liboperit_proot.so`、`libsudo.so`
- `liboperit_ripgrep.so`、`libtensorflowlite_jni.so`、`libsherpa-mnn-jni.so`

Java 依赖与构建输入仍可能留在源码树中，不等于普通版 APK 提供对应能力。相关入口应不可用；负向路径的完整设备验收尚未完成。

普通版也不承诺：跨应用无障碍自主执行、Root、Shizuku、OEM DSP 唤醒。本预览不会自动获取 Root，也不会改动已安装的旧应用。本机 VAD 使用 onnxruntime。16KB 页面对齐的静态打包门禁不等于 16KB 真机已验收。

## 4. 我们如何处理信息

就当前共同版源码与数据清单的定向阅读：**未发现由我们运营的云中转、强制遥测或广告上报**。聊天在您发送后发往**您自己填写**的服务地址，而不是我们的服务器。是否实际发出请求，取决于您是否保存接口配置并发送内容。

### 4.1 聊天内容

您输入的文字、语音转写出的文字、模型回复，以及您选择附带的记忆或文件摘录，会：

1. 保存在本机数据库（应用私有目录中的会话库）；
2. 在您发送消息时，传输到您配置的 AI 接口（普通版要求 HTTPS，见第 6 节）。

我们不把聊天内容上传到自有云。对方服务商如何存储、训练或再处理，适用其自己的政策；本应用无法代为撤回已发送内容。

### 4.2 语音

默认语音识别在**本机**完成：应用使用麦克风采集音频，在设备上转写成文字后进入聊天。默认路径不会把原始录音作为聊天附件上传。默认引擎为 sherpa-ncnn。

您可以在语音设置中改选云端 STT。一旦改选，录音会被发送到您填写的 STT 地址。该选项在设置中仍可达，不属于默认行为。未改选时，不会因为代码里存在第三方 STT 占位地址就自动上传录音。

### 4.3 语音播报（TTS）

默认使用系统 TTS 引擎朗读回复。系统引擎是否联网、是否把文本发到引擎厂商，由该引擎及其系统设置决定，本应用不能保证「完全本机、永不联网」。

您也可以改选 HTTP / 其他云端 TTS。此时待播报文本会发往您填写的地址。

连续语音、自然插话和可听播报的完整验收尚未完成。存在停止入口不等于声学插话已经通过。

### 4.4 图片与其他附件

相册走系统照片选择器，不申请读取全部媒体的权限。拍照走外部相机，普通版不持有相机权限。您主动选择的附件会在本机保存副本；发送消息时，附件说明或内容可能随聊天一并发往您配置的 AI 接口。默认不把图片按多模态直接上传；若您在模型配置中打开直接处理图片，则图片数据可能随请求离开设备。

### 4.5 密钥与接口配置

您填写的 AI / TTS / STT 地址、模型名和密钥保存在本机应用配置存储中，**按明文写入** DataStore / 偏好文件，没有另行加密。发送请求时，密钥作为鉴权信息发往**您填写的地址**。我们不在自有服务器保存您的密钥。卸载应用会清除应用私有目录中的这些配置。

### 4.6 崩溃信息

应用可在本机展示崩溃堆栈，并允许您复制或导出为本地文件。定向阅读未发现自动上传到开发者服务器的实现。

### 4.7 我们不作为普通版处理的信息

共同版清单已去掉精确位置、短信、通话、蓝牙扫描、相机权限、全盘存储等权限。未发现以广告为目的的标识采集实现。最终权限以实际安装 APK 的清单为准。

## 5. 本机存储、备份与删除

| 信息 | 存放 | 您可以如何删除 |
|---|---|---|
| 会话与消息 | 本机数据库 | 在应用内删除会话（锁定的会话会拒绝删除）；也可在设置中批量删除 |
| 模型配置与密钥 | 本机配置存储，明文 | 可删除非默认配置；卸载应用会清除应用私有数据 |
| 语音引擎选择 | 本机配置存储 | 修改设置或卸载 |
| 本机语音模型 | 应用私有目录 | 随卸载清除 |
| 相机临时文件 | 应用缓存 | 取消拍照或进程恢复后清理 |
| 已选附件副本 | 本机公共下载目录下的应用子目录 | 应用退出清理逻辑以实现为准；卸载后该公共目录**可能残留**，需您手动删除 |
| 聊天备份（若您开启） | 由您在设置中导出或调度 | 您可关闭调度并删除导出文件 |
| 记忆库（若您使用） | 本机 | 您在相应界面删除；卸载清除应用私有部分 |

应用不为会话设置自动过期：在您删除或卸载前，上述本机数据会保留。

普通版已关闭系统自动备份（`allowBackup=false`），并排除云备份与设备迁移所覆盖的数据域；整个私有数据目录的 DocumentsProvider 已从共同版移除。用户主动导入/导出仍保留。厂商定制备份是否仍可能拷贝应用数据：**未做 OEM 备份实测**，不能写成「任何备份均不可能发生」。

删除本机数据**不能**从您已调用的 AI / TTS / STT 服务商处撤回内容。

## 6. 第三方、传输与 HTTPS

离开本机的目的地只有：

- 您配置的 AI、TTS、STT 地址；
- 系统 TTS、外部相机、系统设置、系统照片选择器等由系统或您已安装应用处理的界面。

普通版网络配置要求系统证书和 HTTPS；`usesCleartextTraffic` 为 false，填写 `http://` 地址会被网络安全配置拒绝。增强版允许明文 HTTP，不属于本政策承诺。

默认配置里可能出现第三方接口占位名称，不表示我们与该服务商存在运营协议，也不表示数据会在您未配置密钥、未发送消息时自动上传。

## 7. 权限（普通版预期用途）

最终以实际安装 APK 为准。当前共同版 overlay 预期保留的权限用途如下：

- 麦克风：仅在您开启语音时用于本机转写或您改选的云端转写；
- 网络：访问您配置的接口；查看网络状态；
- 前台服务（含麦克风类型）：保持语音对话在后台仍可录音或同步；
- 通知：启动时可能请求，拒绝后仍应可以使用核心聊天（该项须在人工验收中确认）；
- 悬浮窗：可选的悬浮语音窗口；
- 修改音频设置：语音路由；
- 其他保活/语音交互相关权限：用于前台服务或系统语音交互组件。产品首轮**不会**把本应用设为系统默认助手。

打开系统设置或系统相册必须经您当场确认；您拒绝则不执行。
